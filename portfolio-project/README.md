# Interactive 3D Portfolio Room

โปรเจกต์นี้โหลดรูปภาพและวิดีโอ **จากไฟล์ที่วางไว้ในโฟลเดอร์จริง** ไม่ใช่ให้ผู้ใช้เลือกไฟล์ตอนเปิดเว็บ
(เหมือนเว็บอ้างอิงที่ให้มา ซึ่งดึงรูป/วิดีโอจากโฟลเดอร์ assets ของโปรเจกต์)

## โครงสร้างไฟล์

```
portfolio-project/
├── index.html
├── style.css
├── script.js
└── assets/
    ├── models/
    │   └── room2.1.glb        (มีให้แล้ว ใช้โมเดลตั้งต้นของคุณ)
    ├── photos/                 (ใส่รูปของคุณที่นี่)
    │   ├── foto1.jpg
    │   ├── foto2.jpg
    │   ├── foto3.jpg
    │   ├── paint1.jpg
    │   ├── paint3.jpg
    │   ├── paint3_001.jpg
    │   └── paint4.jpg
    └── video/
        └── tv.mp4              (ใส่วิดีโอของคุณที่นี่)
```

## วิธีใช้

1. เตรียมรูปภาพของคุณ ตั้งชื่อไฟล์และนามสกุลตามตารางด้านบน แล้ววางไว้ในโฟลเดอร์ `assets/photos/`
   (ถ้าจะใช้ไฟล์ .png ก็แก้พาธใน `script.js` ที่ตัวแปร `PHOTO_SOURCES` ให้ตรงกับนามสกุลไฟล์จริง)
2. เตรียมวิดีโอ .mp4 ของคุณ ตั้งชื่อ `tv.mp4` วางไว้ที่ `assets/video/tv.mp4`
   (หรือเปลี่ยนชื่อไฟล์ก็ได้ แค่แก้ค่าตัวแปร `VIDEO_SOURCE` ใน `script.js` ให้ตรงกัน)
3. ไฟล์ไหนยังไม่มี ระบบจะข้ามไปเฉยๆ กรอบจะยังเป็นสีเดิมของโมเดล ไม่ทำให้เว็บพัง
4. เปิด `index.html` ผ่านเว็บเซิร์ฟเวอร์ในเครื่อง (เช่น VS Code Live Server) — **ห้ามเปิดไฟล์ตรงๆ แบบ `file://`**
   เพราะเบราว์เซอร์จะบล็อกการโหลดโมเดล/รูป/วิดีโอด้วยเหตุผลด้าน security (CORS)

## Deploy ขึ้น GitHub Pages

1. สร้าง repository ใหม่บน GitHub แล้วอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ (รวมโฟลเดอร์ `assets/` ที่มีรูป/วิดีโอของคุณแล้ว) ขึ้นไป
2. ไปที่ Settings → Pages → เลือก branch `main` โฟลเดอร์ `/ (root)` แล้ว Save
3. รอสักครู่ เว็บจะขึ้นที่ `https://<username>.github.io/<repo-name>/`

## การโต้ตอบในหน้าเว็บ

- **ลากเมาส์** = หมุนกล้องรอบห้อง, **เลื่อนล้อ** = ซูมเข้า-ออก
- **คลิกกรอบรูป/ภาพวาด** = เปิดรูปขยายเต็มจอ (lightbox)
- **คลิกทีวี** = เล่น/หยุดวิดีโอ

## ปรับแก้เพิ่มเติม

- ชื่อ node ของกรอบรูปและทีวีอ้างอิงจากชื่อ object ในไฟล์ `room2.1.glb` เดิม (`foto1`, `foto2`, `foto3`, `paint1`, `paint3`, `paint3.001`, `paint4`, `tv`) — ถ้าคุณแก้โมเดลใน Blender แล้วเปลี่ยนชื่อ object ต้องแก้ชื่อใน `PHOTO_SOURCES`/`TV_NODE_NAME` ใน `script.js` ให้ตรงกันด้วย
- ถ้ารูปเข้าไปแล้วทิศทาง/การหมุนไม่ตรง สามารถปรับด้วย `texture.rotation`, `texture.repeat` ใน `script.js` ได้ (ดูจุดที่ตั้งค่า `tex.encoding` เป็นจุดเริ่มปรับ)
